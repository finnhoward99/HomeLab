# HomeLab
Hands-on IT and cybersecurity homelab documenting systems administration, networking, security and troubleshooting projects.

## About This Lab
This repository documents my hands-on IT and cybersecurity learning through my personal homelab. The lab is used to build practical experience with systems administration, networking, troubleshooting and security.

## Current Environment
- Proxmox VE virtualization host
- Ubuntu Server virtual machine
- Windows virtual machines
- Linux virtual machines
- Self-hosted game servers

## Project Goals

- Build practical IT support and systems administrations skills.
- Develop a strong understanding of networking
- Gain hands-on experience with Windows Server and Active Directory.
- Learn Microsoft 365 and Microsoft Entra ID administration.
- Develop Linux administration and troubleshooting skills.
- Build practical cybersecurity, monitoring and incident response skills.
- Document projects, troubleshooting and lessons learned.
